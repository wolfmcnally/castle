Before disposing private recovery intent, inventory every property later retries must still prove and identify its independently durable surviving witness. A safe-looking completion identity does not prove original path equality when that identity can be copied. Check witness lifetime against the final post-cleanup retry, not only interruption before cleanup.

The namespace contract required every explicit recovery to reject a different same-ID replica path, but kept root commitments only in private intent that successful cleanup removed. A completed public cutover followed by a copied successor root reproduced admission after the only equality witness was gone. Existing marker identities, epoch chain and six-field SQL completion could not distinguish that path. The scoped correction preserves two original root hashes in selection-free SQL completion, validates their source/target joins before disposal and checks exact supplied-root equality before payload I/O or cleanup. Missing, malformed and old-schema evidence refuse without inferring proof from the caller. Unsalted hashes remain guessable/linkable and are not authentication or path secrecy.

The existing namespace restart family now exercises actual completed cutovers, original-root positive retry, different-root replicas with no CAS payload reads, malformed/NULL/old-schema controls and unchanged refused database bytes. The original failed probe, accepted old contract and advisory evidence remain preserved. This is a candidate engineering lesson, not a graduated rule or authorization to retain selected private payload.
