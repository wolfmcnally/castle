When the pinned watcher refuses a role dispatch before launch (here: "primary advice requires a registered evidence run"), the governed-recovery rule applies: preserve the refusal, classify it, and park unless an existing explicitly authorized recovery covers it. Re-dispatching the same role through another venue (a native subagent) without registration produces non-qualifying work, consumes review budget and needs later reconciliation. For design or review work that has no plan phase, the qualifying route is a registered phase that accurately describes the design work, then the normal preflight, evidence initialization, registration and watcher dispatch. The skill could state explicitly that independent advice outside a registered evidence run is research, never review.
