Inspect the exact phase-wide advisory allowance ledger before registering the first current-run review. A fresh run directory, new local attempt counter or not-started phase marker does not establish an unused phase-wide budget. Preserve earlier claims even when their report directory is absent; an unavailable artifact is unknown evidence, and its filename does not establish what scope was reviewed.

The current code launch was rejected before child dispatch because an earlier claim already consumed one pass and the remaining pass required a recorded cause. The original rejected attempt and empty streams were retained. One documented immutable reexecution with a concrete cause used the remaining pass for the current candidate's sole actual code report; no budget, identity, phase name or review venue changed. Next time, inspect the ledger first, use the supported cause-bound path only when headroom and authority exist, and park that dependent review if the allowance is exhausted. This provisional lesson changes no rule or tool and grants no reset.
