# Provenance

Castle was developed by Wolf McNally and is licensed under MIT. This public tree was prepared from source commit `f06fa05f929b15c6bd1d0768733de2673e351eda`. It retains the product implementation, synthetic package tests, canonical methodology skills, policies, tools and their behavioral tests. Earlier private Git history, activity logs, execution observations and operator queues are excluded.

The source-tree proof baseline and disposition ledger are carried forward as technical evidence for the same retained proof estate. Consumer-specific schema text in one historical parameterized proof label is redacted to its public equivalent; original records are retained privately. The public baseline inventory digest and its structural ledger references are recomputed for the redacted serialization. Historical oracle text and measured effectiveness evidence continue to identify the original private baseline; no historical execution is claimed for the redacted bytes. They are sourced records, not newly invented historical dispositions. The unchanged frozen mutation corpus was rerun against disposable public-tree copies after toolchain adaptation; the effectiveness report contains that completed execution unchanged, with its known miss visible. The standalone contributor runtime configuration and its fixtures are adapted together. New release validation is reported separately.

The product runtime depends only on Python’s standard library. Compact schema discriminators name record families and structural versions. Ordinary runtime supports only the current journal discriminator; private offline conversion and consumer validation remain separate from package publication.
